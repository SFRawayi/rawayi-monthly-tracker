# Rawayi Monthly Tracker

Month-by-month view of every Rawayi order (Shopify + Proship status) and customer return (Shopify + Delhivery status).

- Starts from September 2026. Each month refreshes **every hour** from the 1st until the **15th of the next month**, then it is final.
- Tabs per month in the Google Sheet: `Orders 2026-09`, `Returns 2026-09`, …
- Files: `index.html` + `config.js` go on GitHub Pages. `apps-script/*.gs` go into the Google Sheet's Apps Script — never on GitHub.
